Before you start

Can I run several stages over several days?

Yes. New-event setup supports 1–14 days, 1–5 stages and 1–12 bands in total per day. Edit the example timings and names to match your event.

Do crew members need to buy an app?

No. Contributor access is included in the organiser’s allowance: larger teams for a Festival Pass, smaller teams per concert on concert subscriptions. The same apps are intended to be free to install for participants. Native participant mode is not released yet; personal browser links currently allow assigned-work updates and require suitable website access during private testing.

Does this sell tickets or manage admission?

No. This edition coordinates production; it does not sell tickets, scan admissions or replace professional safety management.

What does the critical path calculate?

The longest dependency chain uses durations and one predecessor per moment. Waiting gaps are excluded. Reordering makes selected day/area timings consecutive and keeps dependencies, so review all warnings.

What about weddings and birthdays?

Visit BigDaySorted for celebrations, guest lists, seating, gifts and thank-you notes.

Can I bring over an existing concert plan?

Export the .bigday planning file from BigDaySorted and import it in LiveDaysSorted’s Event settings. Invitations, media and private gift records are not included in planning exports.
